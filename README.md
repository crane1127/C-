
# YIyicleaner

YIyicleaner 是一个面向 Windows 用户的 C 盘清理工具，中文名为“一叶清理”。它的目标很简单：帮助普通用户看懂 C 盘空间被什么占用，并尽量安全地清理缓存、临时文件和部分软件残留。

> 项目当前仍在开发和整理中，清理类工具请谨慎使用。执行清理前建议先确认扫描结果，并保留重要文件备份。

## 功能特点

- C 盘空间扫描：展示已用空间、可用空间和占用比例。
- 分类清理项：按缓存文件、个人文件、软件数据等类别展示扫描结果。
- 风险分级：用安全、需确认、谨慎等等级提示清理风险。
- 勾选后清理：用户选择项目后再执行清理，避免直接误删。
- 专业软件扫描：包含 Adobe、Office、WPS、CAD 等软件缓存方向的扫描逻辑。
- 深色/浅色主题：内置主题资源。
- 中英文切换：支持运行时语言切换。
- 报告导出和历史记录：支持导出扫描结果并查看历史导出记录。
- 管理员权限：通过 `app.manifest` 请求管理员权限，以便清理需要权限的路径。


默认安装目录：

```text
C:\Program Files\YiyeCleaner
```



## 安全说明

磁盘清理工具天然具有风险。本项目的设计原则是：

- 扫描阶段只读，不主动删除文件。
- 清理前展示项目和大小，由用户勾选后执行。
- 对个人文件、软件数据等高风险项目进行风险提示。
- 尽量避免清理系统核心目录。

即便如此，仍建议在清理前确认路径和文件类型，重要资料请提前备份。
